## 🍔 Hamburgueria

Este projeto foi desenvolvido durante as aulas de JavaScript com o objetivo de aprofundar os conhecimentos em métodos de manipulação de arrays, como `forEach`, `map`, `reduce` e `filter`.

A aplicação simula uma hamburgueria com ações automatizadas utilizando JavaScript, permitindo interagir com os produtos e aplicar diferentes operações sobre os dados exibidos na página.

Durante o desenvolvimento, também foram praticados conceitos como manipulação do DOM, eventos e interação entre JavaScript e HTML.


## ⚙️ Funcionalidades

* Exibição dos produtos da hamburgueria na página.
* Exibição de todos os produtos utilizando `forEach`.
* Aplicação de desconto nos produtos utilizando `map`.
* Soma dos valores dos produtos utilizando `reduce`.
* Filtragem dos produtos de acordo com suas características utilizando `filter`.
* Interação com a página por meio de JavaScript e manipulação do DOM.
* Ações automatizadas por meio de eventos JavaScript.



## 🚀 Como executar o projeto

1. Clone este repositório:

```bash
git clone git@github.com:jonatasandradedev/Hamburgueria-site.git
```

2. Acesse a pasta do projeto:

```bash
cd Hamburgueria-site
```

3. Abra o arquivo `index.html` no navegador.

> 💡 Para uma melhor experiência durante o desenvolvimento, o projeto pode ser executado utilizando a extensão **Live Server** no VS Code.
